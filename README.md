# Homebrew tap for Agentty

[Agentty](https://www.agentty.run) — the terminal for AI coding agents.

```sh
brew install --cask empty-user77/agentty/agentty
```

Requires macOS 13+ on Apple silicon. The app is signed with Developer ID, notarized by Apple, and updates itself.
The cask is updated with every release on [agentty-releases](https://github.com/empty-user77/agentty-releases/releases).
